# Sumi Trail — Mobile 3D Adventure

An original, lightweight Three.js adventure inspired by ink-wash landscapes. This is not the original Sumiro game or its unpublished source/assets.

## Play
Open the deployed `/mobile-sumiro/` route in Android Chrome. Landscape is recommended.

## Controls
- Left joystick: move
- Drag the right side of the screen: rotate camera
- Jump: jump
- Climb: upward vault for raised ledges
- Strike: remove nearby roaming shadows
- Dash: quick forward burst (hold for a run)

Desktop: WASD / arrow keys, Space to jump, E to vault, J to strike, Shift to run.

## Hosting
Static page; Three.js is loaded from jsDelivr. The first launch requires internet access. The service worker caches the page shell after it is opened once.
